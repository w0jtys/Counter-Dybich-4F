.NET MAUI Counter 
Prosta aplikacja wieloplatformowa typu "Counter" napisana w .NET MAUI, służąca do zarządzania wieloma licznikami z poziomu interfejsu graficznego.


Funkcjonalności i spełnione wymagania

* Dynamiczne liczniki: Możliwość dodawania nieograniczonej liczby liczników z własnymi nazwami.
* Wartość początkowa: Umożliwia zdefiniowanie początkowej wartości licznika w momencie jego tworzenia.
* Modyfikacja stanu: Przyciski zwiększania (+), zmniejszania (-) oraz usuwania (DEL) dla każdego elementu.
* Trwałość danych (XML + XDocument): Automatyczny odczyt oraz zapis stanów liczników do pliku XML counters.xml w katalogu aplikacji przy każdej zmianie (auto-zapis) oraz podczas uruchamiania.

Technologie

* C# / .NET MAUI 9.0
* LINQ to XML System.Xml.Linq
* INotifyPropertyChanged do powiązań danych
